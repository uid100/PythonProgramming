**Author:** Daniel Sullivan

**Units:** 4 Units  
**Hours:** 3 Hours Lecture, 3 Hours Laboratory

---

# Catalog Description

Introduction to the discipline of computer science using the Python programming language with an emphasis on problem solving, algorithm development, object-oriented programming, and software engineering fundamentals. Students design, implement, test, debug, and document software solutions using structured programming techniques, functions, collections, file processing, exception handling, and classes. Students apply computational thinking and algorithmic problem-solving methodologies to develop maintainable software applications while utilizing professional programming practices and appropriate AI-assisted development tools. Laboratory instruction includes program development, testing, debugging, and execution.
The course is intended as a first college-level programming course aligned with transfer-oriented Computer Science pathways.

# Course Objectives

Students will be able to:

1. Design, implement, test, and debug Python programs using fundamental programming constructs.
2. Analyze problems and develop appropriate algorithms to generate software solutions.
3. Apply structured decomposition techniques to break complex problems into manageable components.
4. Utilize variables, expressions, data types, and assignment statements appropriately.
5. Implement sequence, selection, and repetition control structures.
6. Develop modular applications using functions and parameter passing.
7. Explain programming language paradigms and the evolution of programming languages.
8. Demonstrate understanding of scope, visibility, binding, and lifetime of variables.
9. Design and implement object-oriented software using classes and inheritance.
10. Apply software engineering principles including documentation, readability, maintainability, and testing.
11. Create applications that utilize files, collections, and exception handling.
12. Evaluate, test, and debug software using systematic debugging methodologies.
13. Analyze and validate AI-assisted code for correctness, efficiency, and maintainability.
14. Develop complete software solutions that satisfy stated requirements.
