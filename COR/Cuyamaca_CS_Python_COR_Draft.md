# COURSE OUTLINE OF RECORD

# COMPUTER SCIISE XXX – INTRODUCTION TO PYTHON PROGRAMMING

**Author:** Daniel Sullivan

**Units:** 4 Units  
**Hours:** 3 Hours Lecture, 3 Hours Laboratory

## Catalog Description

Introduction to the discipline of computer science using the Python programming language with an emphasis on problem solving, algorithm development, object-oriented programming, and software engineering fundamentals. Intended as a first college-level programming course aligned with transfer-oriented Computer Science pathways, this course introduces students to computational thinking, structured program design, testing, debugging, and documentation. Students design, implement, test, and debug software solutions using variables, control structures, functions, collections, file processing, exception handling, and classes. Students apply algorithmic problem-solving methodologies to develop maintainable software applications while utilizing professional programming practices and appropriate AI-assisted development tools. Laboratory instruction includes program development, testing, debugging, and execution.
