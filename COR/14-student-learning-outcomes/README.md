# Student Learning Objectives (SLOs)

requirements:
* observable
* measurable
* demonstrable through an assignment, project, or exam
* broad enough to represent a major course outcome
* few in number


1. **Decompose problems and design program solutions using flowcharts, pseudocode, models, or other tools.**
   - Measures computational thinking and design.
   - aligns with structured design and COMP-122 expectations
2. **Properly code applications using the fundamental coding structures: sequence, selection, and loops.**
   - Directly measures mastery of the core programming constructs covered in the course.
   - Supports core constructs. Aligns with other CORs
3. **Test and debug applications using debugging tools such as trace execution.**
   - Aligns well with best practices and overall comp.sci pathways.
