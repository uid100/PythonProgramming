# C-ID alignment

_This content section is not part of the standard template for the college yet, but likely needed and strengthens articulation_

## Included documented points are summary points:

### Programming Fundamentals
- Variables, data types, expressions, assignment, input/output, selection, iteration, functions, and decomposition.
- Write programs using fundamental control structures.
- Demonstrate program design and implementation.
### Algorithms and Problem Solving
- Develop algorithms before coding and use problem decomposition techniques.
- Implement, test, and debug algorithmic solutions.
- Emphasis on computational thinking rather than syntax alone.
### Programming Language History and Paradigms
- Review programming languages inception and evolution.
- Discuss procedural and object-oriented paradigms and tradeoffs among approaches.
### Object-Oriented Programming Concepts
- Create classes and objects.
- Explain encapsulation and abstraction.
- Object-oriented thinking is a core expectation of COMP 122.
### Scope, Visibility, Binding, and Lifetime
- Observe variables behave in different contexts.
- Examine local vs. global scope.
- Demonstrate parameter passing and variable lifetimes.
### Hands-On Programming, Testing, and Debugging
- Experience implementing solutions requiring compilation/execution, testing, troubleshooting, and refinement.
- Practical programming competence is demonstrated through projects and labs.
### Software Engineering Fundamentals and Professional Practices
- Follow coding standards.
- Document and test code.
- Use structured development approaches.
- Learn maintainable design practices appropriate to introductory software development.
