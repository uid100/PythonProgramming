## Introductory Python Programming (4 Units: Combined Lecture and Laboratory)

**Term Length:** 16 Weeks  
**Discipline:** Computer Information Systems / Computer Science  
**Course Type:** Degree Applicable Credit Course

---

## Purpose

Rationale, calculations, and instructional hour distribution for a proposed **4-unit Introduction to Python Programming course** offered during a standard 16-week semester. The calculations align with California Community College credit-hour guidance and Title 5 requirements.

---

# Regulatory Framework

California Community Colleges calculate units based on total student learning hours, including:

- Instructor-supervised classroom/laboratory hours
- Expected outside-of-class student work
- Total learning hours divided by the district's approved hours-per-unit divisor

Title 5 establishes a minimum of **48 semester hours of total student work per unit**. Many California Community Colleges use **54 student learning hours per unit** when developing Course Outlines of Record.

---

# Standard Ratios

- **Lecture:** 1 hour in class : 2 hours outside work
- **Activity/Lab with Homework:** 2 hours in class : 1 hour outside work
- **Traditional Laboratory:** 3 hours in class : 0 hours outside work

---

# Recommended Course Structure

Because students learn programming most effectively through guided coding practice, debugging, hands-on exercises, and project development, a combined lecture/laboratory format is recommended.

## Proposed Unit Distribution

- Lecture: **3.0 Units**
- Laboratory: **1.0 Unit**
- Total: **4.0 Units**

---

# Total Course Hours

- Lecture Contact Hours: **54**
- Laboratory Contact Hours: **54**
- Outside-of-Class Hours: **108**
- Total Student Learning Hours: **216**

Calculation:

```text
216 Total Student Learning Hours ÷ 54
= 4 Units
```

## Laboratory

108 Hours ÷ 16 Weeks

# Program Review Justification

The proposed 4-unit Introductory Python Programming course reflects current industry expectations that students acquire both conceptual understanding and practical coding proficiency.

The combination of lecture and laboratory instruction provides sufficient time for:

- Problem solving and algorithm development
- Python syntax and programming fundamentals
- Variables, data types, and expressions
- Selection and iteration structures
- Functions and modular design
- Lists, dictionaries, and data collections
- File processing
- Exception handling and debugging
- Integrated programming projects
- Workforce and transfer preparation

The allocation of **54 lecture hours, 54 laboratory hours, and 108 hours of outside work for a total of 216 student learning hours** supports the award of **4 semester units** and aligns with California Community College credit-hour standards.
